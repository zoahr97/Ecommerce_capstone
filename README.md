# The Baking Corner

Academic grade: 96/100

The Baking Corner is a full-stack e-commerce web application for browsing and purchasing baking products. The system provides a complete shopping experience for customers, alongside a dedicated administration area for managing products, inventory, and orders.

The client side was developed with **React**, using React Router for navigation, reusable components, forms, and protected routes. The server was developed with **Node.js** and **Express**, and the application uses a **MySQL** database to manage users, products, orders, and order items.

# Key Features

- User registration and login
- Secure authentication using **JWT**
- Password hashing with **bcrypt**
- Role-based authorization for customers and administrators
- Product catalog with available stock information
- Shopping cart with quantity validation based on inventory
- Checkout flow and order creation
- Personal order history and order cancellation
- Automatic stock restoration when an order is cancelled
- Admin panel for managing products, stock quantities, and customer orders
- Protected API endpoints using authentication and administrator middleware

# Technologies

**Frontend:** React, React Router, JavaScript, CSS, Axios  
**Backend:** Node.js, Express  
**Database:** MySQL  
**Security:** JWT, bcrypt  
**Tools:** Git and GitHub
